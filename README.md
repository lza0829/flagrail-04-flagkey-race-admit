# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

领域：**基础设施** · 子方向：**中间件**

## 开关键竞态准入（已落地 · 架构甲：单胜出）

两客户端同时给同一开关键塞 v3/v4，此前的空桩会在指针/世代上出现 **双当前** 或 **后写无痕覆盖**。
本模块把「入轨 + 当前指针 + 世代分配」钉成 **同票**（同一 `BEGIN IMMEDIATE` 独占写事务），并选定 **架构甲（单胜出）** 贯彻到底：

- **库内仅一版已入轨，当前唯一**：任一开关键任一时刻至多一个活跃版本，`当前版本` 指针唯一且指向它。
- **冲突方入轨失败可查**：并发败者**不入库**、不覆盖，写入 `冲突单`（被拒版本键 ↔ 现行版本键 ↔ 提议世代 ↔ 原因/时刻），可审计。
- **下发必须钉版**：`下发票.钉版` = 该开关键当前指针版本键；非当前版 / 空指针一律失败闭（409）。
- **入轨与下发交错永不钉空版本**：两者同在写锁内读指针；后到者排队（`busy_timeout`）重读，要么读到已入轨的胜出版，要么按空指针失败闭，绝不写空钉版。
- **世代链**：每次成功准入分配该开关键下一代（`开关版本.世代`），当前指针记录当前世代；回滚/失效清指针，可再入轨下一代。

并发结局**可区分**（甲口径）：并发后 `行数=1`、`活跃=1`、`当前键`唯一 —— 与乙口径（两行皆入轨、指针指最高世代）在核证响应里由 `架构` 字段直接标明。

### 核证接口

```
GET /api/核证?开关键=<key>      # 单键：行数 / 活跃数 / 当前键 / 当前世代 / 冲突单 / valid
GET /api/核证                    # 全键：{架构, 口径, 项[], 有效}
GET /api/冲突单?开关键=<key>     # 冲突单据
```

`valid` 判定（甲）：活跃已入轨版本 ≤ 1；有活跃版当且仅当指针非空；指针不得悬空/指向非活跃版；活跃版必须就是当前指针所指之版。任一不成立 → `valid=false`，且 `/api/贯验` 不通过。

### 压测入口与脚本断言

```
POST /api/竞态/开关键   {开关键, 版本号:[3,4]}
```

服务端两线程各占独立连接、`Barrier` 同时起跑、各自 `BEGIN IMMEDIATE` 塞 v3/v4。返回 `胜出 / 冲突 / 核证 / 断言{当前唯一, 指针非双, 冲突方留痕, 库内版本数, valid}`。

界面联动：`开关轨` 页展示当前指针、冲突单，并一键「并发塞 v3/v4」；`下发票` 页可对任意版本键试下发以亲见「非当前版失败闭」；`轨贯验` 页附核证汇总。
